    Questions

    Is it free?

    Yes. The site and its source code are free. Developers set their own prices.

    Who can see my request?

    The developer you chose sees it. Contact details you add are visible only to that developer.

    Can I change or cancel my request?

    You can edit it while it is new or in progress, and you can cancel it while it is new.

    Why should I keep the tracking link?

    The tracking link is the only way back to your request unless you use the same browser. Anyone with the link can see that request, so keep it private.
