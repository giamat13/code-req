# 0003: Tracking links are bearer tokens

- Status: Accepted
- Date: 2026-10-21

## Context

Requesters should not need an account to send a request or to follow its progress. Without accounts, the server needs some way to tell a requester apart from everyone else.

## Decision

Each request document ID is 20 random characters, generated by Firestore. The tracking link `track.html?r=<requestId>` is the only way back to the request. Anyone who has the ID can read that request, post messages in its thread, and cancel it while it is still `new`. Nobody can list requests except their developer.

## Consequences

- If a tracking link leaks, the people who receive it can read and cancel that one request. The UI tells requesters to keep the link private.
- Firestore rules allow `get` on requests and their messages for anyone, and `list` only for the owning developer.
- Requests are not searchable, and the developer's dashboard is the only place that lists them.
